## Hi there

I'm **Kyungmin Lee**, an engineer interested in the space where **hardware and software meet**.

I mainly enjoy thinking about **SoC architecture**, **system-level performance**, **memory/cache systems**, and the kind of engineering decisions that make complex systems practical. This GitHub is where I keep experiments, notes, tools, and projects that reflect what I am learning and building.

---

## About Me

- Currently working around **SoC / System IP / architecture-oriented engineering**
- Interested in **performance modeling**, **computer architecture**, and **HW/SW co-design**
- Comfortable moving between low-level systems thinking and practical software tooling
- I like clear explanations, useful abstractions, and projects that make hard systems easier to understand
- Writing and organizing thoughts at [shumin.co.kr](https://shumin.co.kr/)
